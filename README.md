# 🔐 Sistema de Login

[![GitHub Pages](https://img.shields.io/badge/🌐-Site%20Online-blue?style=for-the-badge)](https://leandrostanger.github.io/SistemaDeLogin/)
[![GitHub](https://img.shields.io/badge/📂-Repositório-black?style=for-the-badge)](https://github.com/LeandroStanger/SistemaDeLogin)

Um sistema de login moderno e responsivo, desenvolvido com HTML, CSS e JavaScript, para controle de acesso em aplicações web.

## ✨ Funcionalidades

- **📝 Interface de Login e Cadastro:** Formulários intuitivos para autenticação e criação de nova conta de usuário.
- **🔐 Validação de Campos:** Verificação em tempo real dos dados inseridos nos formulários.
- **💾 Armazenamento Local:** Os dados dos usuários são salvos diretamente no navegador utilizando o `localStorage`.
- **🎨 Design Responsivo:** Layout adaptável que funciona perfectly em dispositivos desktop e mobile.
- **🔒 Feedback Visual:** Mensagens de erro e sucesso para uma melhor experiência do usuário.

## 🚀 Como Usar

### Acesso Online
Você pode acessar o sistema diretamente através do GitHub Pages:  
**[https://leandrostanger.github.io/SistemaDeLogin/](https://leandrostanger.github.io/SistemaDeLogin/)**

### Execução Local
Se preferir executar o projeto localmente em sua máquina:

```bash
# Clone o repositório
git clone https://github.com/LeandroStanger/SistemaDeLogin.git

# Acesse a pasta do projeto
cd SistemaDeLogin

# Abra o arquivo index.html em seu navegador
# Ou utilize um servidor local, como:
python -m http.server 8000
```

## 🛠 Tecnologias Utilizadas

As seguintes tecnologias foram empregadas no desenvolvimento deste projeto:

- **HTML5** - Estrutura semântica da aplicação
- **CSS3** - Estilização e design responsivo
- **JavaScript (ES6+)** - Lógica de programação e interatividade
- **Local Storage API** - Armazenamento local dos dados de usuário
